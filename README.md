# School Report System Frontend

React + Vite + Tailwind UI for the multi-school report SaaS.

## Run

```bash
npm install
npm run dev
```

App: http://localhost:5173  
API proxy: `/api` → http://localhost:8080

## Dev logins (password `Password123!`)

- `super@reports.local` — platform schools & templates
- `admin@newlight.local` / `director@newlight.local` / `head@newlight.local`
- `teacher.nursery@newlight.local` / `teacher.primary@newlight.local`
